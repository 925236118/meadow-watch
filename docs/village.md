# 村庄、信件和随机事件

主界面提供信箱、农场/村庄切换及明日/后天天气。地图小屋旁的信箱可点击，村口道路免费进入独立村庄场景。四位村民在道路上漫步，点击时停下，打开个人互动面板；关闭后继续走动。村民名单保留为快速入口。商店、邮局和公告栏分别接入已有交易、信箱、订单、互助与预告。雨天自动灌溉，村民在屋前停留更久；事件期间会在公告栏前多停留。

## 好感度与日常互动

| 村民 | 喜欢 | 不喜欢 |
| --- | --- | --- |
| 王伯 · 村长 | 小麦、鸡蛋 | 矿石 |
| 小林 · 记者 | 鲜鱼、胡萝卜 | 南瓜 |
| 阿禾 · 菜农 | 卷心菜、南瓜 | 鲜鱼 |
| 梅姨 · 店主 | 玉米、鸡蛋 | 矿石 |

全村共用每天前三次免费对话，之后不限次数、每次消耗 1 AP。每位村民每天仅第一次成功对话增加 0.25 星，重复聊天不会增加好感，但仍能听到可用的小道消息。重复聊天也计入三次免费额度；AP 不足的失败对话不扣次数。次日重置。

每位村民每天可赠礼一次，消耗物品一份、0 AP，喜欢 +0.5 星，普通 +0.25 星，不喜欢 -0.25 星。好感范围 0–5 星，星形旁显示精确数值。每天对话并送喜欢的礼物，第 7 天满星；只对话，第 20 天满星（未计互助、讨厌礼物）。

首次达到 1、2、3、4、5 星分别收到纪念信，下降再升回不会重复触发。3 星附随机种子三颗，4 星附一次保护，5 星附一份证据。每个村民独立计算。

## 酒馆与村民台词

村庄右侧酒馆可喝酒闲聚：每次 1 AP，随机 2–3 位不同村民各获得最多 0.25 星好感，仍受 5 星上限约束。酒馆独立于每日首次对话，也不占前三次免费聊天额度，可以继续用 AP 参加。每次听到一条消息，优先新预告，无新预告时重谈已知事件或接下来两天的天气。结果随存档保存、可完整撤回，重复撤回不会重抽同一次客人。

人物背景和性格是内部写作依据，不作为界面档案展示。台词按 0–5 星选择关系口吻，再结合各自日常事务、天气、事件、鸡群、砍树、疲劳与互助生成，好友来信也区分人物。使用本地原创文本组合，无外部服务依赖。

建筑使用真实 TileMapLayer 拼接。可编辑模板为 `scenes/wooden_house.tscn`，屋顶、墙体、檐口、门窗分层，TileSet 为 `assets/tilesets/wooden_house.tres`；商店、酒馆、小屋和邮局共用，采用指定两张木屋图集。

## 信箱与互助（详细规则）

信件包含问候、请求、感谢、好感纪念、小道消息、事件公告、证据关联及保护通知。阅读标记和附件领取状态保存在存档中。种子、证据、保护必须点击领取，不能重复领取。

同一时间一个特殊请求，随机需要鸡蛋、鲜鱼、矿石、胡萝卜或小麦两份，发布日加三天结束前可完成。交付 0 AP，声望 +1、该村民好感 +0.5 星；感谢信随机附种子三颗、证据两份或一次保护。请求截止后刷新，无超时惩罚。保护可累计，每次公司破坏作物时抵消一次，并收到保护通知信。

## 小道消息与事件

事件提前两天安排；初始消息预告第 4 天事件。村民对话会透露一条可用的新消息，喜欢的赠礼可能带来消息，日常来信也可能预告。商店消息基础价 12 金币、享受声望折扣，每天最多买一条；没有未透露的未来事件时不出售。所有预告显示准确起止日期。

| 事件 | 效果 |
| --- | --- |
| 矿洞修缮 | 暂停挖矿，失败操作不扣 AP |
| 新矿脉发现 | 每次挖矿 +2 矿石 |
| 鱼塘清洁 | 暂停钓鱼，失败操作不扣 AP |
| 鱼类繁殖 | 每次钓鱼 +2 鲜鱼，污染仍可减少鱼获 |
| 种子涨价 / 降价 | 种子基础价 ×1.25 / ×0.8，再计算声望优惠 |
| 作物涨价 / 降价 | 作物售价 ×1.2 / ×0.8，向下取整，再计算公司市场打压 |

持续 1–3 天，结束日当日仍生效，次日恢复。相同领域不会重叠，村庄事件加公司干扰最多同时两项。鱼、鸡蛋和矿石售价不受作物行情影响；背包和商店标价与结算使用相同函数。

## 证据关联

调查河岸、矿洞、村口分别得到检测记录、用工合同、收购报价。成功赠礼线索或领取证据信件可得到排放照片、欠薪记录、真实估价之一。证据册的关联面板显示缺少或持有的卡片，配齐两张可关联一次，0 AP、证据 +1，并收到记者来信。

| 关联 | 所需卡片 |
| --- | --- |
| 排污与检测不符 | 河岸排污检测 + 夜间排放照片 |
| 合同掩盖欠薪 | 矿洞用工合同 + 工人的欠薪记录 |
| 压低土地估价 | 土地收购报价 + 真实土地估价 |

所有新状态均可保存；当天对话、赠礼、阅读、领取、互助、消息购买、证据关联支持撤回。独立保存村庄随机状态，读取或撤回不会重复抽换互助奖励或改变同一消息。旧存档自动初始化新系统。

旧十星存档按完成比例转换，例如 6/10 星变为 3/5 星，分数精度保留。原 2/4/6/8/10 星里程碑转换为 1/2/3/4/5 星，信件文字同步，已读和领取状态保留，不重复发奖；旧撤回记录同样转换。没有对话计数的旧档按今天已对话的村民数恢复已用额度。
